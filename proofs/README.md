# Proofs, reviewed like code

Write each proof you want reviewed (pset or textbook problem) as a Markdown file here, then get it reviewed the way you'd review code:

1. `git checkout -b proof/5-1-odd-sum`
2. Copy `TEMPLATE.md` to `proofs/ch05/odd-sum.md` and write the proof. Write it on paper first if you can, then type it up.
3. Push and open a pull request.
4. Ask the tutor to *review my proof PR*. It leaves line-by-line review comments, the way a careful senior engineer would on a code PR.
5. Fix, push, and repeat until the verdict is **correct**. Then merge.

Every mistake found in review goes into `progress/mistakes.md`.
