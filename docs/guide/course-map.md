# Course map

This follows the **Spring 2024** run of 6.1200J (Erik Demaine, Zachary Abel, Brynmor Chapman): 24 lectures in 6 units. Readings are the course's own recommendations from *Mathematics for Computer Science* (Lehman, Leighton, Meyer; CC BY-SA), included in this repo as `mcs.pdf`. Videos: [OCW lecture videos](https://ocw.mit.edu/courses/6-1200j-mathematics-for-computer-science-spring-2024/video_galleries/lecture-videos/).

**For each lecture:** watch the video → do the reading → do this site's lessons for those sections → do the problems.

✅ means a lesson exists on this site.
